# ImageRendering

「图片的样子」是一款面向设计师与开发者的图片适配演示工具：用同一张图，直观看到三种常见渲染模式在不同区域比例下的差异，减少沟通成本。

### 主要功能：

#### 1. 模式对比：同一比例区域下，一屏对比 拉伸/适配/铺满（Scale To Fill / Aspect Fit / Aspect Fill）
+ 预置 1:1、4:3、16:9
+ 支持自定义比例（输入宽高）
+ 支持纵向/横向/网格多种排列方式
#### 2. 模板对比：同一渲染模式下，多比例区域并排预览
+ iPhone 屏幕比例（机型/分辨率）
+ 顶部区域比例（状态栏 + 导航栏）
+ 头像/卡片（方形/圆形）
+ 自定义模板分组（比例或分辨率录入）
#### 3. 安全内容计算器：在铺满且居中裁切的前提下，计算多机型“始终可见”的安全区域
+ 安全区域比例、裁切百分比
+ 像素范围参考，便于放置关键内容与文字

使用说明：渲染模式速览 + 常见误区（变形/留白/裁切）
